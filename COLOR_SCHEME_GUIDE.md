## Usage Guidelines

### Where Colors Are Applied

1. **Primary Color** - Main sidebar background
2. **Primary Light** - Hover states, subtle backgrounds
3. **Gold/Accent** - Links, buttons, accent elements
4. **Active Highlight** - Background of selected menu items
5. **Subtitle** - Secondary text, breadcrumbs
6. **Logo Icon Bg** - Circle behind logo icon
7. **Logo Icon Text** - Icon/text inside logo circle
8. **Active Nav Text** - Text color of active menu item
9. **Active Nav Border** - 3px left border on active items
10. **Avatar Bg** - User avatar circle background
11. **Avatar Text** - User initials color
12. **Page Title** - Main page heading in top bar

### Color Psychology by Theme

**Linen & Burgundy:**
- Warmth: Creates welcoming environment
- Trust: Deep burgundy conveys reliability
- Sophistication: Cream linen adds elegance

**Premium Gold:**
- Luxury: Gold accents suggest premium service
- Prosperity: Associated with success and wealth
- Stability: Olive green provides grounded feel

**Sky Blue:**
- Clarity: Represents clear communication
- Trust: Blue is universally trusted color
- Freshness: Modern, clean appearance

**Royal Purple:**
- Royalty: Premium, exclusive feeling
- Creativity: Suggests innovation
- Distinction: Unique, memorable brand

## Implementation Notes

### How to Change Theme

Users can switch themes from:
- **Settings** page (after login)
- Theme selector in sidebar
- Changes apply instantly (no page refresh needed)

### Default Theme

- **Linen & Burgundy** is set as the default theme
- Automatically applied on first login
- User preference saved in localStorage

### Browser Compatibility

All colors have been tested for:
- ✅ Accessibility (WCAG contrast ratios)
- ✅ Color blindness compatibility
- ✅ Mobile device displays
- ✅ Dark mode screens

## Color Contrast Ratios

All themes maintain WCAG AA compliance:
- **Text on Primary:** > 4.5:1 contrast ratio
- **Accent on White:** > 3:1 contrast ratio
- **Logo/Avatar:** Optimized for readability
